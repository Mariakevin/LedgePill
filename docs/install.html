One line, then it lives up there.

The installer detects your package manager, pulls the GTK4 stack and sets up a user service. Prefer packages? There are native builds for the big three.

Any distro

Universal installer

Handles Arch, Debian/Ubuntu and Fedora, installs dependencies, then enables the service.

$ curl -fsSL https://raw.githubusercontent.com/Mariakevin/LedgePill/main/packaging/install.sh | sudo bash

Read it before you pipe it to a shell — it's a plain bash script in the repo.

Arch Linux

Build from the PKGBUILD

$ git clone https://github.com/Mariakevin/LedgePill $ cd LedgePill/packaging && makepkg -si
Debian 12+ / Ubuntu 24.04+

The .deb

Grab it from Releases, then install:

$ sudo apt install ./ledge-pill_*.deb

APT pulls the dependencies automatically; Python 3.11+ is required. libgtk4-layer-shell0 is optional and missing from some Ubuntu releases — without it the island falls back to a floating window.

Fedora

The .rpm

$ sudo dnf install ledge-pill-*.rpm
After install

Start it, keep it

$ ledge-pill # try it $ systemctl --user enable --now ledge-pill.service # keep it

Works natively on Wayland compositors that speak layer-shell — KDE Plasma, Hyprland, Sway, river, Wayfire and friends. On GNOME Wayland, which gives apps no layer-shell, it falls back to a plain floating window.
